# HR-ANALYTICS-DASHBOARD
Interactive Power BI Dashboard for HR Analytics & Employee Attrition. This project features an interactive Power BI dashboard built to analyze workforce performance, employee retention, and attrition drivers. The primary goal is to transform raw HR data into actionable, visual insights regarding employee turnover, satisfaction levels, salary dynamics, and tenure trends.
